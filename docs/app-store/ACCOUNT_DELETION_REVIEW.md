# App Store 账号注销（Guideline 5.1.1(v)）

## 功能位置

登录后：**更多** → 页面底部 **注销账号**（位于「退出登录」下方）

## 流程（审核录屏建议）

1. 注册新账号，或使用演示账号登录  
2. 进入「更多」页，滑到最底部  
3. 点击「注销账号」  
4. 第一次弹窗：阅读不可恢复提示 → 点「继续注销」  
5. 第二次弹窗：再次确认 → 点「确认注销」  
6. 提示「账号已注销」，回到欢迎页  
7. 使用同一用户名重新注册可成功（证明账号已删除）

## 接口

`DELETE /api/v1/auth/me`（需登录 Bearer Token）  
服务端将硬删除账号及关联业务数据，并清理用户媒体目录。
