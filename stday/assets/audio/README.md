# Star Island Audio Placeholders

Replace this file with the real audio assets below before enabling production audio QA.

## Background Music

- `bgm_island_day_loop.mp3`
- `bgm_island_night_loop.mp3`
- one growth trajectory track with `insights` or `instights` in the filename
- one More/settings track with `more` in the filename

Example:

- `bgm_insights_loop.mp3`
- `bgm_more_loop.mp3`

## Sound Effects

- `sfx_tap_soft.wav`
- `sfx_task_complete.wav`
- `sfx_growth_gain.wav`
- `sfx_level_up.wav`
- `sfx_moment_saved.wav`
- `sfx_vip_success.wav`

The app catches missing audio asset errors and skips playback silently, so these
filenames can be wired before final audio files are available.
